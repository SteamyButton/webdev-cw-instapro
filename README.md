# Instapro

MVP социальной сети для обмена фотографиями

## Внесённые исправления:

### Интеграция ленты с API:

- статическая разметка постов заменена динамической;
- посты формируются из данных, полученных через API;
- добавлено сообщение для пустой ленты.

### Добавление публикаций

- реализована отправка нового поста в API;
- после успешной отправки обновлённый пост появляется в общей ленте.

### Страница пользователя

- реализовано получение публикаций отдельного пользователя через API;
- добавлено сообщение на случай отсутствия публикаций.

### Лайки

- реализована постановка и снятие лайков через API;
- добавлено условие для отображения активной и неактивной иконки;
- количество лайков рассчитывается по длине массива пользователей;
- иконка и счётчик обновляются без перерисовки всей ленты;
- лайки работают в общей ленте и на странице пользователя;
- неавторизованному пользователю показывается предупреждение о необходимости войти.

### Дополнительные доработки

- даты публикаций переведены в относительный формат с помощью date-fns;
- пользовательский HTML-код экранируется;
- добавлена обработка ошибок API;
- изображения постов адаптированы для мобильных экранов;
- проект настроен для запуска и сборки через Vite.

## Запуск проекта

Установить зависимости:
npm install

Запустить проект:
npm run dev

Создать итоговую сборку:
npm run build

Проверить собранную версию:
npm run preview
